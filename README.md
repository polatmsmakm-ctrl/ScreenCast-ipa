# بث (ScreenCast)

تطبيق آيباد/آيفون: بث الشاشة كاملة لأصدقائك + مكالمة صوتية جماعية، عبر Tencent TRTC.

## الرفع والبناء
1. سوّ ريبو جديد على GitHub (مثلاً `ScreenCast`) وارفع كل محتوى هالمجلد (بما فيه مجلد `.github`).
2. روح Actions ← Build IPA ← يشتغل تلقائياً (أو Run workflow).
3. نزّل `ScreenCast-ipa` من الـ Artifacts وثبّته بـ Sideloadly.

## مفاتيح تينسنت (ما تحتاج تعدل كود)
1. سوّ حساب على Tencent Cloud ← TRTC ← Create Application.
2. انسخ **SDKAppID** و **SDKSecretKey**.
3. افتح التطبيق ← ⚙️ ← الصقهم. كل صديق يحط نفس القيم.

## الاستخدام
- الكل يكتب اسمه ونفس اسم الغرفة ويدخل (الصوت يشتغل جماعي مباشرة).
- اللي يبي يبث يضغط «ابدأ بث الشاشة» ← تطلع نافذة النظام ← «ابدأ البث».
- الجودة من زر الإعدادات: 720p / 1080p / 1080p نص واضح.

## ملاحظات
- البث بدون App Group (حسابك المجاني ما يدعمه). تينسنت تقول الثبات يقل شوي.
- أقصى دقة للبث 1080p.
- مفتاح تينسنت السري يتخزن داخل جهاز كل صديق (مناسب لتطبيق خاص بكم فقط).
